`@eliware/path`. The requirements and out-of-scope documents define the
contract that implementation and tests must satisfy. See the root
[README](../README.md) for user-facing documentation.

## Documents

- [Requirements](requirements.md) — mandatory API and architecture behavior.
- [Out of scope](out-of-scope.md) — behavior this package intentionally does
  not provide.
