# Basic usage

Prerequisites: Node.js 26 or newer and dependencies installed with `npm
install` from the repository root.

Run the example with:

```text
node examples/basic/example.mjs
```

Expected result: the command prints the directory containing this example and
the path to `config.json`; it performs no filesystem or network I/O.

Use only placeholder paths in copied examples. Never put passwords, tokens, or
other secrets in example arguments.
